# Survivors (CDT501 Lecture 9 test)

A small Vampire Survivors-like game in Python with pygame-ce, made with a coding agent (Qoder + Qwen3.8-Flash).

Play in the browser: https://lingnantest007.github.io/survivors-test/

Run on your computer: `python -m pip install pygame-ce pillow`, then `python main.py`.
Walk toward the mouse pointer (or keep your finger on the screen). Weapons fire by themselves.
